Buddy Frontend Skill

Conventions for the Buddy Angular 22 frontend in `src/frontend/buddy`: zoneless standalone components with signals, runtime-config-backed API services, Tailwind 4 theming, accessibility patterns, routing, and colocated Vitest specs. Use it when creating or changing Angular components, routes, services, templates, styling, or unit tests.

It lives at `agents/copilot/buddy-frontend/` as a Copilot/Codex/GitHub Pilot agents package skill.

Files:
- `SKILL.md` - The ported frontend conventions and workflow, with the original technical guidance preserved and Claude-specific frontmatter removed.
- `manifest.json` - Metadata for the Copilot agents package version of the skill.
- `README.md` - Short description of the skill and the files shipped in this directory.
- `spec-patterns.md` - Copied frontend unit-test patterns and snippets referenced by `SKILL.md`.
