Copilot skill package for Buddy frontend translation work. Use it when adding, renaming, rewording, or removing user-facing strings in the Angular app, wiring translation keys into templates or TypeScript, and checking English/Danish parity before finishing.

Files:
- `SKILL.md` — translation architecture, usage patterns, workflow steps, validation commands, and gotchas.
- `manifest.json` — skill metadata.
- `check-parity.mjs` — parity checker for missing keys, placeholder mismatches, identical values, and optionally unused keys.
