Backend-Aware Review Skill

Review a diff for correctness bugs and reuse/simplification/efficiency cleanups, with Buddy-specific grounding for any backend or `.NET` files in the change. Use it for staged diffs, working-tree diffs, commits, branches, or PRs when you want backend review informed by `agents/copilot/claude-backend/SKILL.md` and, when available, `dotnet-skills` plugin guidance instead of a generic pass.

Files:
- `SKILL.md` — review workflow, backend/.NET routing rules, inline checklist, and reporting guidance.
- `manifest.json` — skill metadata.
- `README.md` — package overview and file list.
