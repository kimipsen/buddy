Feature from Analysis Skill

Build a Buddy feature end to end from a design doc in `docs/backend/analysis/` or `docs/frontend/analysis/`, or write a new analysis doc that a later implementation pass can build from. Use it when turning a proposed feature into backend slices, frontend routes/components/services, i18n, Playwright coverage, screenshots, and shipped documentation, or when you need to draft that design first.

This package coordinates companion skill docs such as `agents/copilot/claude-backend/SKILL.md`, `agents/copilot/backend-feature/SKILL.md`, `agents/copilot/buddy-frontend/SKILL.md`, `agents/copilot/i18n/SKILL.md`, `agents/copilot/e2e-test/SKILL.md`, `agents/copilot/run-buddy/SKILL.md`, `agents/copilot/doc-screenshots/SKILL.md`, and `agents/copilot/backend-aware-review/SKILL.md`.

Files:
- `SKILL.md` — end-to-end workflow from analysis doc to shipped feature, plus the path for writing a new analysis doc.
- `manifest.json` — skill metadata.
- `README.md` — package overview and file list.
- `references/analysis-doc-template.md` — template and checklist for analysis docs, shipping updates, and doc registration.
