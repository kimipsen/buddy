E2E Test Skill

Guidance for Buddy Playwright end-to-end tests in `src/frontend/buddy/e2e`, including prerequisites, execution, result inspection, failure triage, and conventions for real-stack test data and locators. Use it when writing or debugging Playwright specs for Buddy.

It lives at `agents/copilot/e2e-test/` as a Copilot/Codex/GitHub Pilot agents package skill.

Files:
- `SKILL.md` - The full Playwright e2e testing guide, ported without YAML frontmatter.
- `manifest.json` - Metadata for the Copilot agents package version of the skill.
- `README.md` - Short description of the skill and the files shipped in this directory.
